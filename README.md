# Κάρτες Συνεργατών Γ.Ν. Βέροιας — OCR 10

Η έκδοση 10 **διατηρεί αυτούσια τη φωτογράφιση από την κανονική κάμερα POCO και το crop της έκδοσης 9**. Οι αλλαγές είναι μόνο στην αναγνώριση εταιρείας.

- Αναγνωρίζει περισσότερες ελληνικές και λατινικές επωνυμίες, ακόμη και χωρίς λέξεις όπως «Medical» ή «Hospital».
- Αναλύει το OCR και από τα δύο περάσματα (ελληνικά+αγγλικά / ελληνικά).
- Αποκλείει διευθύνσεις, τηλέφωνα, websites και πιθανές γραμμές ονοματεπωνύμου από τις προτάσεις.
- Προτείνει πιθανές εταιρείες κάτω από το πεδίο «Εταιρεία» με κουμπιά για επιλογή.
- Συμπληρώνει αυτόματα μόνο όταν υπάρχει ισχυρή και σχετικά ξεκάθαρη ένδειξη. Διαφορετικά αφήνει το πεδίο κενό για επιβεβαίωση.
- **Δεν αλλάζει κανένα υπάρχον δεδομένο** στο IndexedDB. Χειροκίνητες καταχωρίσεις δεν αντικαθίστανται αυθαίρετα.

## Ενημέρωση GitHub Pages

1. Κράτησε πρώτα αντίγραφο ασφαλείας από την επιλογή «Αρχείο».
2. Ανέβασε τα τέσσερα αρχεία **app.js, styles.css, sw.js και index.html** στο root του bantonis/gn-verias-visitcards, αντικαθιστώντας τα προηγούμενα. Μην ανεβάσεις αυτούσιο το ZIP.
3. Περίμενε να ολοκληρωθεί η δημοσίευση GitHub Pages. Κλείσε και άνοιξε ξανά την εφαρμογή στο κινητό.
4. Επιβεβαίωσε την ένδειξη **«Έκδοση OCR 10»** και δοκίμασε ξανά την ίδια κάρτα.

Οι προτάσεις είναι **υποψήφιες**, όχι εγγυημένα σωστές. Αν η εταιρεία δεν υπάρχει στο αναγνωρισμένο κείμενο, δεν μπορεί να ανακτηθεί αξιόπιστα από τον parser: άνοιξε «Προβολή του κειμένου OCR» για διάγνωση.
