# Κάρτες Συνεργατών Γ.Ν. Βέροιας — OCR 12

## Τι διορθώθηκε

- Δίγλωσσες και κατακόρυφες κάρτες: το ονοματεπώνυμο **Δημήτριος Ι. Ζαφειρίου** προκρίνεται από την ιδιότητα **Καθηγητής Παιδιατρικής**.
- Ιδιότητες όπως «Καθηγητής Παιδιατρικής», «Νευρολογίας / Αναπτυξιολογίας» και «Professor of Child Neurology» δεν προτείνονται ως όνομα ή εταιρεία.
- Προσωπικά ονόματα (ακόμη και με αρχικό πατρώνυμου) δεν προτείνονται ως εταιρείες. Το πεδίο **Εταιρεία** παραμένει κενό όταν η κάρτα αφορά φυσικό πρόσωπο χωρίς εμφανή επωνυμία.
- Επιπλέον αγγλικό OCR στο κάτω μέρος **μόνο όταν λείπει κινητό ή το email είναι αμφίβολο**, για αριθμούς και λατινικά email. Αβέβαια email δεν συμπληρώνονται αυτομάτως.
- `T/F` (τηλέφωνο/fax) επιτρέπει τον ίδιο σταθερό αριθμό στα δύο πεδία. Το σαφές `FAX` εξακολουθεί να αφαιρεί τον αριθμό από τη λίστα των σταθερών.
- Η κανονική κάμερα POCO, η περικοπή φωτογραφίας, η αναγνώριση ελληνικών, η τοπική αποθήκευση και το σύστημα backup **δεν αλλάζουν**.

## Ενημέρωση GitHub Pages

1. Εάν έχεις ήδη αποθηκεύσει κάρτες, πάρε αντίγραφο από **Αρχείο → Λήψη backup** (JSON).
2. Άνοιξε το repository: https://github.com/bantonis/gn-verias-visitcards
3. Από **Add file → Upload files** ανέβασε **app.js, index.html, sw.js** στη ρίζα, αντικαθιστώντας τα προηγούμενα, και πάτησε **Commit changes**.
4. Περίμενε το πράσινο ✓ από **Actions → pages build and deployment**.
5. Κλείσε και άνοιξε ξανά την εφαρμογή. Στην οθόνη «Νέα κάρτα» πρέπει να γράφει **Έκδοση OCR 12**. Αν η παλιά παραμένει, δοκίμασε με ανώνυμη καρτέλα για να ξεχωρίσουμε το cache από τη δημοσίευση — **μην σβήσεις δεδομένα εφαρμογής**.
6. Για δοκιμή, χρησιμοποίησε **νέα** καταχώριση ή σβήσε παλιά λανθασμένα πεδία και επίλεξε «Επανάληψη OCR». Οι χειροκίνητες διορθώσεις διατηρούνται όπου είναι δυνατόν.

## Όρια & έλεγχος

Οι κανόνες ελέγχθηκαν με δοκιμαστικά κείμενα (καθηγητής/ιατρός, τεχνικός, δύο διαφορετικές εταιρείες), και ο JavaScript κώδικας πέρασε έλεγχο σύνταξης. **Δεν έχει επιβεβαιωθεί ακόμη** η πραγματική συμπεριφορά OCR 12 στο POCO. Σε δύσκολες φωτογραφίες ίσως χρειάζεται χειροκίνητη διόρθωση. Μην αποθηκεύεις στοιχεία ασθενών ή άλλα ευαίσθητα δεδομένα.
