# Κάρτες Συνεργατών — Έκδοση OCR 11

## Διόρθωση εταιρείας

- Δεν προτείνει ιδιότητες (π.χ. «Διευθυντής Γ΄ Ογκολογικής Κλινικής») ως εταιρείες.
- Απορρίπτει παραμορφωμένες σειρές από λογότυπα (π.χ. «ΞΞΞΞΣ, ΕΣ»).
- Όταν η αναγνώριση επωνυμίας είναι αβέβαιη, διαβάζει ξεχωριστά το επάνω τμήμα της κάρτας με αγγλικό OCR.
- Αν δεν βρει αξιόπιστη επωνυμία, αφήνει το πεδίο κενό για χειροκίνητη συμπλήρωση, αντί να συμπληρώσει λάθος.
- Η κανονική κάμερα, η περικοπή, το όνομα, το Fax και τα υπόλοιπα πεδία παραμένουν ως στην έκδοση 10.

## Ενημέρωση GitHub

Ανέβασε στην **αρχική σελίδα** του αποθετηρίου τα `app.js`, `index.html`, `sw.js`. Δεν χρειάζεται να αντικαταστήσεις τα υπόλοιπα. Μετά το commit περίμενε να ολοκληρωθεί το GitHub Pages deployment. Θα εμφανίζεται **Έκδοση OCR 11**.

**Πριν από την ενημέρωση:** Από «Αρχείο» κάνε πλήρες JSON backup εφόσον έχεις καταχωρίσεις. Μην κάνεις εκκαθάριση δεδομένων/απεγκατάσταση.

**Σημαντικό:** Αν το πεδίο της εταιρείας περιέχει ήδη λάθος κείμενο από την προηγούμενη σάρωση, σβήσε το πριν πατήσεις «Επανάληψη OCR». Η εφαρμογή δεν αντικαθιστά χειροκίνητα καταχωρισμένες τιμές.

Οι αλλαγές έχουν ελεγχθεί με δοκιμαστικά OCR κείμενα και έλεγχο σύνταξης, όχι με πραγματική κάμερα POCO.
