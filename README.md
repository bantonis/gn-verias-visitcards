# Κάρτες Συνεργατών Γ.Ν. Βέροιας — OCR 8

## Διορθώσεις κάμερας
- Η εφαρμογή ζητά **συνεχή αυτόματη εστίαση**, μόνο όταν ο browser το υποστηρίζει.
- Προστέθηκε κουμπί **«Εστίαση ξανά»**, για νέο αίτημα autofocus όπου επιτρέπεται.
- Προστέθηκε ρύθμιση **χειροκίνητης εστίασης** μόνο αν ο browser επιστρέφει σχετικές δυνατότητες.
- Αν η συσκευή εκθέτει περισσότερες από μία πίσω κάμερες, μπορείς να επιλέξεις άλλη κάμερα.
- Το πλαίσιο **1,75:1**, το OCR, οι αποθηκευμένες κάρτες και η κανονική κάμερα παραμένουν.

**Περιορισμός:** Ορισμένες εκδόσεις Chrome/Android δεν επιτρέπουν στο web app να ελέγξει τον φακό ή δεν παρέχουν επιλογή εστίασης. Το κουμπί εμφανίζεται απενεργοποιημένο όταν δεν υπάρχει διαθέσιμος έλεγχος. Για καθαρή λήψη δοκίμασε 20–30 εκ. απόσταση, καλό φωτισμό, σταθερή λήψη. Αν η προεπισκόπηση παραμένει θολή, χρησιμοποίησε «Κανονική κάμερα» — συνήθως έχει πληρέστερο έλεγχο autofocus.

## Ανέβασμα στο GitHub
1. Πάρε **backup** από το Αρχείο της εφαρμογής, αν υπάρχουν σημαντικές καταχωρίσεις.
2. Αποσυμπίεσε το ZIP ενημέρωσης.
3. GitHub → repository `bantonis/gn-verias-visitcards` → Add file → Upload files.
4. Ανέβασε στον **root** φάκελο τα νέα `app.js`, `styles.css`, `sw.js` και επίλεξε αντικατάσταση των αρχείων.
5. Πάτησε **Commit changes** και περίμενε να ολοκληρωθεί το GitHub Pages deployment.
6. Κλείσε/άνοιξε ξανά την εγκατεστημένη εφαρμογή και έλεγξε ότι γράφει **«Έκδοση OCR 8»**.

Τα δεδομένα παραμένουν τοπικά στο IndexedDB, **δεν** ανεβαίνουν στο δημόσιο GitHub. Μην ανεβάζεις backups ή φωτογραφίες εκεί.
