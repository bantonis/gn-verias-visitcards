# Κάρτες Συνεργατών Γ.Ν. Βέροιας — Έκδοση OCR 9

Επιστροφή στην **κανονική κάμερα κινητού** (native camera), με βελτιωμένο autofocus της συσκευής. Μετά τη λήψη ακολουθεί **οθόνη περικοπής**, η οποία επιχειρεί αυτόματα να αναγνωρίσει τα όρια της επαγγελματικής κάρτας. Ο χρήστης μπορεί να μετακινήσει το πλαίσιο και να σύρει τις 4 γωνίες πριν επιβεβαιώσει **«Περικοπή & OCR»**.

- Το crop εφαρμόζεται στην αρχική ανάλυση της φωτογραφίας, πριν από OCR και αποθήκευση.
- Η αυτόματη αναγνώριση λειτουργεί κυρίως όταν η κάρτα έχει αντίθεση από το φόντο· όπου δεν είναι σίγουρη, απαιτείται χειροκίνητη επιλογή.
- Όλα γίνονται τοπικά στη συσκευή. Δεν ανεβαίνουν φωτογραφίες σε server.
- Διατηρείται η λογική OCR 6 για ονόματα, σταθερά, κινητά, fax, διεύθυνση, τμήματα, μηχανήματα, παρατηρήσεις.
- Οι ήδη αποθηκευμένες κάρτες παραμένουν. Κράτησε backup πριν από κάθε ενημέρωση.
- Για **GitHub Pages**, ανέβασε τα `app.js`, `styles.css`, `sw.js`, `index.html` στο root του repository (αντικατάσταση παλιών). **Μην ανεβάσεις ZIP αυτούσιο**. Το `index.html` περιέχει έκδοση query `?v=9` για να μειώνονται τα προβλήματα cache.

Η αυτόματη περικοπή είναι βοήθημα, όχι εγγύηση. **Έλεγξε πάντα το περίγραμμα πριν πατήσεις «Περικοπή & OCR»**, για να μη χαθεί μέρος της κάρτας.
