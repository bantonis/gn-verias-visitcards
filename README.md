# Κάρτες Συνεργατών Γ.Ν. Βέροιας — OCR 14

Η προηγούμενη έκδοση 13 βελτίωσε την αναγνώριση ονομάτων με τίτλους (π.χ. «Δήμητρα Κωτσαλή, DVM»), αποφεύγει να καταχωρίζει τον υπότιτλο του λογότυπου ως πρόσωπο ή εταιρεία, διατηρεί περισσότερα από ένα κινητά και περισσότερα από ένα email σε μια επαφή και αναγνωρίζει ιστοσελίδες ακόμη και αν εμφανίζονται στη γραμμή του email.

Στην BioAnalytica, το «BIOTECHNOLOGY SYSTEMS» θεωρείται περιγραφή και το «BioAnalytica» προτιμάται ως επωνυμία εφόσον έχει αναγνωριστεί το κείμενο. Τα ονόματα και οι αριθμοί εξάγονται από το OCR, επομένως **όλα τα πεδία πρέπει να επιβεβαιώνονται πριν από την αποθήκευση**.

## Ενημέρωση GitHub Pages

1. Προαιρετικά αλλά συνιστάται να δημιουργήσετε πρώτα πλήρες backup JSON από Αρχείο → Λήψη backup.
2. Αποσυμπιέστε το ZIP ενημέρωσης.
3. Στο https://github.com/bantonis/gn-verias-visitcards επιλέξτε Add file → Upload files.
4. Ανεβάστε τα τέσσερα αρχεία `app.js`, `styles.css`, `index.html`, `sw.js` στη ρίζα του αποθετηρίου (main). Αντικαταστήστε τις παλαιότερες εκδόσεις.
5. Commit changes. Μετά την ολοκλήρωση της δημοσίευσης GitHub Pages, ανοίξτε την εφαρμογή και ελέγξτε ότι γράφει «Έκδοση OCR 14».
6. Αν η κάρτα υπάρχει ήδη με λανθασμένα πεδία, διορθώστε τα ή επαναλάβετε OCR και επαληθεύστε τα αποτελέσματα πριν αποθηκεύσετε.

Η βάση IndexedDB παραμένει με το ίδιο όνομα (`GNVeriasCardsDB`) και την ίδια έκδοση. Δεν χρειάζεται επανεγκατάσταση ή εκκαθάριση δεδομένων. Οι πολλαπλοί αριθμοί/email φυλάσσονται στο υπάρχον πεδίο με διαχωριστικό ` / `, ώστε τα παλιά backup και CSV να εξακολουθούν να λειτουργούν.

## Περιορισμοί

Οι δοκιμές λογικής έγιναν με κείμενο-δείγματα και όχι με πραγματικό OCR πάνω σε συσκευή POCO. Ενδέχεται να χρειαστεί χειροκίνητη διόρθωση, ιδίως σε κείμενα λογότυπων και γραφιστικά. Όλα τα στοιχεία μένουν τοπικά στη συσκευή (χωρίς συγχρονισμό). Μη διαγράφετε τα δεδομένα εφαρμογής χωρίς πρόσφατο backup.


## OCR 14: επανέλεγχος τηλεφώνων
- Διατηρεί την κανονική κάμερα POCO και το χειροκίνητα ελέγξιμο crop.
- Αν ένα ψηφίο αναγνωριστεί ως O/Ο ή I/Ι/l, ο αριθμός εμφανίζεται ως **αβέβαιη πρόταση** αντί να χαθεί. Δεν συμπληρώνεται αυτόματα.
- Το νέο κουμπί **«Επανέλεγχος μόνο τηλεφώνων»** κάνει ξεχωριστή αριθμητική ανάγνωση. Τα αποτελέσματά της **δεν αποθηκεύονται αυτόματα**. Ο χρήστης επαληθεύει την εικόνα και επιλέγει Σταθερό/Κινητό/Fax.
- Προστέθηκε ανίχνευση σταθερών/fax και από το συμπληρωματικό OCR περιοχής στοιχείων επικοινωνίας.
- Τα πεδία και η βάση IndexedDB δεν αλλάζουν. Απαραίτητο backup πριν από ενημέρωση.
- Δεν εγγυάται σωστούς αριθμούς από θολές φωτογραφίες· πάντα οπτικός έλεγχος.
