# Κάρτες Συνεργατών — Τεχνική Υπηρεσία Γ.Ν. Βέροιας

Πρότυπη εφαρμογή **PWA** για καταγραφή επαγγελματικών καρτών τεχνικών και συνεργατών.

- Φωτογράφιση κάρτας από κινητό.
- Τοπική αναγνώριση ελληνικού/αγγλικού κειμένου (Tesseract.js).
- Στοιχεία επαφής, τμήματα, μηχανήματα και παρατηρήσεις.
- Αναζήτηση, εξαγωγή CSV για Excel και πλήρες JSON backup/επαναφορά.

## Δημοσίευση μέσω GitHub Pages

1. Δημιουργήστε νέο **Public** repository (π.χ. `gn-verias-visitcards`).
2. Με **Add file → Upload files** ανεβάστε **τα περιεχόμενα** του πακέτου στο root του repository (όχι το ZIP ως ενιαίο αρχείο). Το `index.html` πρέπει να είναι στο root.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save**.
4. Μετά τη δημοσίευση η εφαρμογή θα είναι διαθέσιμη στη διεύθυνση `https://<username>.github.io/<repository>/`.
5. Από Chrome σε Android: μενού **⋮ → Εγκατάσταση εφαρμογής** / **Προσθήκη στην αρχική οθόνη**.

## Προσοχή στην ιδιωτικότητα

Η ιστοσελίδα GitHub Pages **είναι δημόσια**. **Μην ανεβάζετε** επαγγελματικές κάρτες, αρχεία εξαγωγής CSV/JSON, προσωπικά δεδομένα, κωδικούς ή στοιχεία ασθενών στο repository. Οι κάρτες που αποθηκεύονται μέσα στην εφαρμογή βρίσκονται **μόνο στη συγκεκριμένη συσκευή και browser** (IndexedDB), χωρίς συγχρονισμό, λογαριασμούς ή κεντρικά αντίγραφα ασφαλείας. Μην τη χρησιμοποιείτε ακόμη ως επίσημο υπηρεσιακό σύστημα χωρίς τις σχετικές εγκρίσεις και έλεγχο ασφάλειας. Τα αποθηκευμένα δεδομένα δεν είναι κρυπτογραφημένα με ανεξάρτητο κωδικό χρήστη.

Το OCR λειτουργεί στο πρόγραμμα περιήγησης, αλλά απαιτεί αρχικά internet για τη λήψη βιβλιοθήκης/γλωσσικών μοντέλων. Ελέγχετε χειροκίνητα τα αναγνωρισμένα στοιχεία.
