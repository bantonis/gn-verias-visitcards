Ενημέρωση OCR 4 — Κάρτες Συνεργατών Γ.Ν. Βέροιας
1. Κάνε πρώτα backup από «Αρχείο» στην εφαρμογή.
2. Αποσυμπίεσε αυτό το ZIP.
3. Στο GitHub repository gn-verias-visitcards: Add file → Upload files.
4. Ανέβασε τα αρχεία app.js, styles.css, sw.js στη ρίζα (ίδια θέση με τα προηγούμενα).
5. Commit changes και περίμενε τη δημοσίευση του Pages.
6. Κλείσε/άνοιξε ξανά την εφαρμογή (ενδεχομένως δύο φορές).
7. Στην οθόνη νέας κάρτας πρέπει να εμφανίζεται «Έκδοση OCR 4».
8. Δοκίμασε αναγνώριση, επιβεβαίωσε όνομα/εταιρεία/ιδιότητα και μετά αποθήκευσε.
Δεν σβήνονται τα δεδομένα IndexedDB, αλλά διατήρησε backup.
